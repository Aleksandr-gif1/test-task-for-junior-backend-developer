# Тест-план для Task API

## 1. Обзор проекта

Backend-сервис на Go (Clean Architecture) для управления задачами с возможностью генерации экземпляров.

**Стек:** Go, PostgreSQL, Docker, REST API

**Документация API:** [Postman Collection](./docs/postman/collection.json)

---

## 2. Цель тестирования

Проверить корректность работы REST API, включая:
- CRUD-операции с шаблонами задач
- Генерацию экземпляров задач
- Каскадное удаление (CASCADE)
- Валидацию входных данных
- Обработку ошибок

---

## 3. Стратегия тестирования

### 3.1 Уровни тестирования

| Уровень | Что тестируем | Инструмент |
|---------|---------------|------------|
| Unit | Бизнес-логика (service layer) | Go testing |
| Integration | API endpoints + БД | Postman |
| E2E | Полные сценарии пользователя | Postman |

### 3.2 Типы тестов

- **Функциональное:** Позитивные и негативные сценарии
- **Валидация:** Проверка входных данных (граничные значения, типы)
- **Интеграционное:** Проверка CASCADE, целостности данных в БД

---

## 4. Тестовое окружение

- **Локальное:** Docker Compose (PostgreSQL + Go-сервис)
- **База данных:** PostgreSQL (тестовая, очищается перед прогоном)
- **Инструмент:** Postman (коллекция с автоматизированными проверками)

---

## 5. Критерии приемки (Exit Criteria)

- ✅ 100% успешное выполнение Postman-коллекции
- ✅ Отсутствие ошибок уровня ERROR/FATAL в логах
- ✅ Корректная работа CASCADE-удаления
- ✅ Все негативные сценарии возвращают ожидаемые коды ошибок (400, 404)

---

## 6. Тестовые сценарии

### 6.1 CRUD операций с задачами

| ID | Сценарий | Метод | Ожидаемый результат |
|----|----------|-------|---------------------|
| TC-01 | Создание задачи с валидными данными | POST /tasks | 201 Created |
| TC-02 | Создание задачи без обязательного поля | POST /tasks | 400 Bad Request |
| TC-03 | Получение списка задач | GET /tasks | 200 OK |
| TC-04 | Получение задачи по ID | GET /tasks/:id | 200 OK |
| TC-05 | Получение несуществующей задачи | GET /tasks/:id | 404 Not Found |
| TC-06 | Обновление задачи | PUT /tasks/:id | 200 OK |
| TC-07 | Удаление задачи | DELETE /tasks/:id | 200/204 |

### 6.2 Генерация экземпляров

| ID | Сценарий | Метод | Ожидаемый результат |
|----|----------|-------|---------------------|
| TC-08 | Генерация экземпляров на 7 дней | POST /tasks/generate?days=7 | 200 OK, создано 7 записей |
| TC-09 | Генерация с days=0 (граничное) | POST /tasks/generate?days=0 | 400 Bad Request |
| TC-10 | Генерация с невалидным days | POST /tasks/generate?days=abc | 400 Bad Request |

### 6.3 Интеграционные тесты

| ID | Сценарий | Метод | Ожидаемый результат |
|----|----------|-------|---------------------|
| TC-11 | CASCADE: удаление задачи удаляет экземпляры | DELETE /tasks/:id | Экземпляры удалены из БД |
| TC-12 | Проверка данных в БД после создания | SELECT запрос | Данные соответствуют API-ответу |
